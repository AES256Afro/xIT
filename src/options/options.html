Custom redirector

For a self-hosted instance or anything not listed. Tokens: {path} {query} {user} {id} {hash} {host}. A plain mirror is usually https://your.host/{path}{query}.

Keyboard shortcut

Copy the tweet under the pointer with the default redirector. Default Alt+Shift+C.

To change it: Chrome chrome://extensions/shortcuts · Firefox about:addons → gear → Manage Extension Shortcuts. Those pages cannot be opened from here, so paste the address in yourself.
