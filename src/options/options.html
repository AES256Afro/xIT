xIT

Copied X links go through the redirector you pick. Nothing leaves your browser.

Choose your redirectors

Add your own or choose from these defaults. Change any time. Select a few to be pinned.

Your own instance

Optional. Tokens: {path} {query} {user} {id}. A plain mirror is usually https://your.host/{path}{query}. Pin it from the list afterwards.

Import settings

Adding keeps your default, your pins and your switches, and brings across only redirectors you do not already have. Replacing takes their whole file, including their choices.

Reset to defaults?

Every setting goes back to how xIT installs: three redirectors enabled, FxTwitter as the default, nothing pinned. Any redirector you added yourself is removed, and so is any catalogue entry you took. This cannot be undone.

A redirector can quietly stop working. Check asks each host whether it still answers, once, when you press it. xIT makes no network request otherwise, and asks for access to a host only at that moment. A host that answers is not proof it can still display tweets.

Custom redirector

For a self-hosted instance or anything not listed. Tokens: {path} {query} {user} {id} {hash} {host}. A plain mirror is usually https://your.host/{path}{query}.

Keyboard shortcuts

Copy the tweet under the pointer with the default redirector: Alt+Shift+C.

Open the tweet under the pointer with the default redirector: not bound. Both browsers hand out the obvious combinations already, so rather than pick one that silently loses, this one is left for you to choose.

To change it, open the browser's own shortcuts page. An extension cannot open that page for you, so copy the address and paste it into the address bar.

chrome://extensions/shortcuts

On Firefox the page is about:addons, then the gear menu, then Manage Extension Shortcuts.
